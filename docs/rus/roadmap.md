# Направления развития

[English](../eng/roadmap.md) · [Документация](README.md)

Текущие возможности и ограничения перечислены в [статусе проекта](status.md).

## Игровые механики

- Завершить правила движения, боя, спавна, добычи и опыта Survival для 1.21.4.
- Добавить оставшиеся действия предметов, эффекты зачарований и специальные меню.
- Завершить обновления блоков, redstone и автоматизацию контейнеров.
- Добавить транспорт, пассажиров, поведение деревень, рейды и боссов.
- Завершить переходы и возрождение в Nether/End.
- Реализовать условия достижений, статистику, подписанный чат и функции датапаков.

Генерация мира и структуры пока отложены.

## Расширяемость и эксплуатация

- Разработать API плагинов и модулей на Go для подключения сторонних расширений.
- Расширить систему прав за пределы уровней оператора.
- Рассмотреть интеграцию с прокси, экспорт метрик и инструменты администрирования.
- Рассмотреть улучшения хранения миров на основе существующей поддержки Anvil.
