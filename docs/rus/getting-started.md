# Установка и первое подключение

[English](../eng/getting-started.md) · [Документация](README.md)

## Скачивание бинарника

Скачайте архив для своей ОС и процессора из [GitHub Releases](https://github.com/VitisMC/Vitis/releases). Выбирайте готовый бинарник, а не архив исходников.

| Платформа | Архив |
| --- | --- |
| Linux x86-64 | `vitis-linux-amd64.tar.gz` |
| Linux ARM64 | `vitis-linux-arm64.tar.gz` |
| Windows x86-64 | `vitis-windows-amd64.zip` |
| macOS Intel | `vitis-darwin-amd64.tar.gz` |
| macOS Apple Silicon | `vitis-darwin-arm64.tar.gz` |

Выпуск содержит контрольные суммы архивов в `SHA256SUMS`. Распакуйте архив в доступный для записи каталог сервера. Архивы Linux/macOS сохраняют права исполнения. Go и Java не нужны; для первоначальной загрузки ресурсов нужен Интернет. Подключение поддерживается для Minecraft Java Edition **1.21.4**.

## Запуск одной командой

Откройте терминал в каталоге, где будут храниться файлы сервера.

Linux/macOS:

```bash
./vitis
```

Windows PowerShell:

```powershell
.\vitis.exe
```

Перед приёмом подключений Vitis создаёт отсутствующие файлы и подготавливает ресурсы:

| Путь относительно рабочего каталога | Первый запуск |
| --- | --- |
| `configs/vitis.yaml` | Стандартные настройки: проверка аккаунтов включена, порт 25565 |
| `configs/tab.yaml` | Шаблоны верхней и нижней части списка игроков |
| `ops.json`, `whitelist.json`, `banned-players.json`, `banned-ips.json` | Пустые JSON-массивы списков доступа |
| `world/vanilla/1.21.4/` | Ресурсы из официального JAR после проверки размера и SHA-1: `data/`, `pack.mcmeta` и файл версии |
| `world/` | Создание и открытие мира |

Подготовка использует временный каталог. После проверки версии Minecraft, протокола, DataVersion и формата датапака сервер компилирует ресурсы. JAR и временные файлы удаляются; готовый пакет остаётся внутри мира. Отчёты `reports/` для запуска не требуются. Существующие файлы не заменяются.

Дождитесь сообщений `preparing server resources`, `server resources loaded` и `Vitis listening`. На той же машине подключайтесь к `127.0.0.1:25565` клиентом 1.21.4 с аккаунтом Mojang. По умолчанию сервер слушает `0.0.0.0:25565`; настройки сети описаны в [конфигурации](configuration.md).

## Конфигурация и рабочий каталог

Относительные пути считаются от **рабочего каталога**, а не от расположения бинарника. Для другого файла конфигурации:

Linux (Bash):

```bash
./vitis -config local.yaml
```

Windows (PowerShell 7.2+):

```powershell
.\vitis.exe -config local.yaml
```

Отсутствующий файл по `-config` создаётся со стандартными настройками. `world.default_world_name` задаёт каталог мира и путь `<world>/vanilla/1.21.4/`. Шаблоны списка игроков и списки доступа остаются относительно рабочего каталога. Неизвестные ключи и некорректные значения останавливают запуск.

[Production-пример](../../configs/vitis.example.yaml) использует проверку аккаунтов, Survival и стандартные дальности. При запуске из корня репозитория используется локальный `configs/vitis.yaml`, если другой путь не указан. При запуске отсутствующие рабочие файлы создаются автоматически; они исключены из Git.

## Остановка и повторный запуск

Введите `stop` в консоли или отправьте SIGINT/SIGTERM. Перед копированием мира дождитесь `Vitis shutdown complete` и успешного выхода процесса. Для повторного запуска используйте ту же команду, рабочий каталог и конфигурацию.

Исправный `<world>/vanilla/1.21.4/` используется без скачивания. Если его нет, сервер проверяет `.mcdata/1.21.4/vanilla` и копирует в мир, сохраняя исходник. Если нет обоих пакетов, скачивает официальный JAR. Повреждённый пакет в любом из этих мест сохраняется и останавливает запуск. Проверка аккаунтов игроков по-прежнему требует Интернета.

Существующий мир должен иметь DataVersion 4189. Его метаданные сохраняются. Перед открытием прочитайте [хранение и резервное копирование](storage.md).

## Ошибки подготовки

Таймаут HTTP-запроса — две минуты, всей подготовки — пять минут. Отмена, ошибка HTTP, неверные размер или контрольная сумма и повреждённый архив останавливают запуск. Неполный пакет не устанавливается. Исправьте причину и повторите команду.

Повреждённый локальный пакет вызывает `prepare server resources failed`. Изучите ошибку, сохраните копию и переместите повреждённый каталог перед новым скачиванием. Ошибки пользовательских датапаков исправляются отдельно; см. [диагностику](troubleshooting.md).

## Сборка из исходников

Для разработки ядра нужны Go 1.23+ и Git. Из корня репозитория:

Linux (Bash):

```bash
go build -o vitis ./cmd/vitis
./vitis -config local.yaml
```

Windows (PowerShell 7.2+):

```powershell
go build -o vitis.exe ./cmd/vitis
.\vitis.exe -config local.yaml
```

Ресурсы подготавливаются так же, как при запуске готового бинарника, без Java. Полная кодогенерация описана в [руководстве разработчика](generators/README.md).
