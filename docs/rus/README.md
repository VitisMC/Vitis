## Изменение документации

Обновляйте оба языка при изменении поведения. Справочник конфигурации содержит строку для каждого YAML-ключа.

Linux (Bash):

```bash
make docs-check
```

Windows (PowerShell 7.2+):

```powershell
go run ./cmd/vitis-doccheck
```

Проверка работает без сети и проверяет цели локальных ссылок, парность страниц EN/RU и покрытие ключей конфигурации. Ссылки на разделы, внешние сайты, перевод, значения по умолчанию и примеры проверяются вручную.
