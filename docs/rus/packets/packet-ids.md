# Идентификаторы пакетов и регистрация

[English](../../eng/packets/packet-ids.md) · [Документация](../README.md)

ID определяется версией, состоянием и направлением. Состояния Login, Configuration и Play повторно используют числовые значения. Направления `toClient` и `toServer` во входных данных соответствуют исходящим и входящим пакетам сервера.

## Два пакета идентификаторов

| Пакет | Назначение |
| --- | --- |
| [internal/protocol/packetid](../../../internal/protocol/packetid/) | Константы, используемые сетевыми кодеками сервера |
| [internal/data/generated/packet](../../../internal/data/generated/packet/) | Совместимые константы [генератора пакетов](../../../internal/data/generator/packet/main.go) |

Генератор обновляет основную таблицу `internal/protocol/packetid/packetid.go` и создаёт совместимые константы `internal/data/generated/packet`. Существующие имена сохранены. Команда `go run internal/data/generator/packet/main.go --check` проверяет оба результата по закреплённым данным протокола 769.

Оба пакета содержат директивы stringer. Полная генерация не запускает все `go:generate`; при смене идентификаторов проверьте и строковые представления.

## Регистрация кодека и обработчика

[Состояния протокола](../../../internal/protocol/states/) регистрируют фабрики пакетов по направлению и состоянию. [Реестр](../../../internal/protocol/registry.go) хранит таблицы с копированием при записи и отклоняет повторную регистрацию одного ключа. [Маршрутизация сессии](../../../internal/session/handler.go) связывает состояние и ID с обработчиком действия.

Для нового пакета добавьте константу, кодек и обработчик. Если действие намеренно не выполняется, укажите это в [политике игровых пакетов](../../../internal/session/play_policy.go).

## Проверка изменения

Сверяйте `.mcdata/<version>/protocol.json` с исходниками и отчётами выбранной версии. Проверяйте числовые ID, имена, состояния, направления и поля пакетов. Не назначайте ID по алфавиту или позиции в старом блоке iota.

Запускайте тесты протокола и сессий с некорректными данными и неверным порядком этапов, затем подключайте клиент нужной версии. Полный процесс описан в [обновлении версии](../generators/version-upgrade.md).
