# Диагностика

[English](../eng/troubleshooting.md) · [Документация](README.md)

Укажите тег выпуска или коммит, версию клиента, рабочий каталог и команду запуска. Для инструментов разработчика добавьте версии Go и Java. Приложите первую связанную ошибку и шаги воспроизведения. Удалите пароли, токены, публичные IP и личные данные игроков.

| Симптом | Что проверить |
| --- | --- |
| `initialize server files failed` | Права записи в родительские каталоги и поддержку жёстких ссылок: через них публикуются готовые файлы настроек без замены существующих. |
| `load config failed` | Файл по `-config`, права каталога, неизвестные поля и некорректные значения. См. [конфигурацию](configuration.md). |
| `prepare server resources failed` | Сеть, настройки HTTPS-прокси и сертификаты, место на диске, контрольные суммы и архив. Исправьте причину и повторите запуск. Повреждённый существующий пакет сохраняется. См. [установку](getting-started.md). |
| `load server resources failed` | Ошибки датапаков и компиляторов, рабочий каталог. При исправном встроенном пакете повторная кодогенерация не нужна. |
| Нет `java` или ошибка `unsupported class version` | Для полной генерации нужны `java` и `javac` из JDK 21 в PATH. Отдельный генератор отчётов требует совместимую JVM. Для запуска сервера Java не нужна. |
| Сбой подготовки исходников при генерации | Скачивание и контрольные суммы инструментов, JDK 21, свободное место и первую ошибку переименования или декомпиляции. См. [генерацию](generators/README.md). |
| `unsupported DataVersion` | Нужен мир версии 1.21.4. Не подменяйте метку версии для обхода проверки. |
| Ошибка резервного копирования | Место, права и типы файлов. Существующий `.vitis-backup` должен быть каталогом. |
| Ошибка чтения списков доступа | Названный JSON-файл; восстановите исправную копию, сохранив исходный файл. |
| Соединение отклонено | Сообщение `Vitis listening`, адрес, порт, межсетевой экран и ошибки сетевой службы. |
| Ошибка входа | Версия клиента 1.21.4, доступность службы сессий Mojang при включённой авторизации, блокировки, повторное подключение и лимит игроков. |
| Белый список отклоняет игрока с аккаунтом Mojang | Добавление по имени вычисляет UUID без проверки аккаунта. См. [эксплуатацию](operations.md). |
| YAML принят, но поведение не изменилось | Часть параметров используется только при старте, часть не подключена. См. [справочник](configuration.md). |
| Перезагрузка конфигурации отклонена | Изменён параметр, требующий перезапуска, либо новое значение не прошло проверку. Действуют прежние настройки. |
| Ошибка `reload` | Первую ошибку компилятора, метаданные, JSON и типы ресурсов. Действует предыдущий набор ресурсов. |
| Не работают scoreboard, team, worldborder или bossbar | Эти команды не подключены к игровым подсистемам. |
| Медленная загрузка новых областей или высокий расход памяти | Дальность видимости, лимит отправки чанков, число обработчиков, прегенерацию и задержки диска. Сравнивайте одинаковые нагрузки. |
| Ошибки остановки или сохранения | Сохраните логи и файлы мира, проверьте резервные копии перед перезапуском или восстановлением. |

Если сетевой пакет принимается, но действие не выполняется, проверьте [статус функции](status.md).

В отчёте об ошибке опишите ожидаемое и фактическое поведение, приложите конфигурацию без секретов и воспроизведение на временном мире. Проверьте результат без пользовательских датапаков. Для проблем производительности укажите нагрузку, число игроков, дальности, начальное значение генерации, измерения, процессор, память и накопитель.

Инструменты разработчика описаны в [тестировании](testing.md). HTTP-интерфейс метрик и профилирования сейчас не настроен.
