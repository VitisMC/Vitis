# Датапаки и список игроков

[English](../eng/resources.md) · [Документация](README.md)

## Загрузка ресурсов

При старте Vitis подготавливает отсутствующий `<world>/vanilla/1.21.4/` без Java, затем загружает его и пользовательские датапаки из `<world>/datapacks/`. Поддерживаются каталоги и ZIP-архивы. Пользовательские пакеты сортируются по пути; определения из более поздних пакетов заменяют предыдущие.

Каталог мира задаётся в `world.default_world_name`. Встроенный пакет загружается перед пользовательскими. Существующий `.mcdata/<version>/vanilla` используется как источник переноса после проверки. Если пакет содержит `version.json`, его версия должна совпадать с константами бинарника. Старые пакеты Vitis без этого файла принимаются только с точным описанием поддерживаемой версии и формата пакета; при копировании в мир добавляется файл версии.

Нужен `pack.mcmeta` с форматом датапака **61**. Пути ресурсов имеют вид `data/<namespace>/<type>/<path>`, например `data/minecraft/recipe/example.json`. В 1.21.4 каталоги `recipe`, `loot_table` и `advancement` названы в единственном числе.

Загрузчик отклоняет символические ссылки, небезопасные пути, повреждённый JSON, повторные записи ZIP и превышение лимитов. Лимиты: 32 МиБ на файл, 512 МиБ на пакет и 65 536 записей ZIP. После чтения JSON определения проверяются компилятором соответствующей подсистемы.

Рецепты, таблицы добычи, естественный спавн, достижения и генерация мира регистрируют компиляторы до первой загрузки. `/reload` загружает и компилирует новый набор ресурсов, затем атомарно применяет его. Если хотя бы один компилятор возвращает ошибку, остаётся предыдущий набор.

Естественный спавн читает `spawners`, `spawn_costs`, границы/свет измерения и тег биомов `more_frequent_drowned_spawns` из compiled snapshot. Заряд и бюджет энергии должны быть конечными числами. Глубина drowned использует текущую настройку уровня моря измерения; поведение генерации мира не добавляется.

Loot раскрывает составные entries и теги предметов перед взвешенным выбором, затем применяет функции singleton, вложенной таблицы, pool и table. `set_components` использует полный codec стека и отклоняет некорректные или неизвестные компоненты перед публикацией. Условия по причине смерти разрешают обязательные/исключаемые теги `damage_type` из того же snapshot; неверные или отсутствующие обязательные ссылки на теги отклоняют reload. Constant, uniform и binomial providers допускают вложенность до 16 уровней; количество binomial trials ограничено 65 536. Другие number providers отклоняются при компиляции. Полный набор loot-функций и предикатов ещё не завершён.

Для проверки замены рецепта скопируйте его JSON из встроенного пакета в тот же относительный путь нового датапака, добавьте `pack.mcmeta` и измените поддерживаемые поля результата или количества. Выполните `reload`, проверьте консоль и крафт на клиенте. Установка датапака не требует изменения сгенерированного Go-кода.

## Список игроков

Отсутствующий `configs/tab.yaml` создаётся при старте из встроенных шаблонов.

`configs/tab.yaml` содержит строки `header` и `footer`. Поддерживаются коды цветов Minecraft `§` и экранированные переводы строк. Путь фиксирован относительно рабочего каталога; файл исключён из Git. Если файл некорректен или оба шаблона пусты, используются [стандартные шаблоны](../../internal/config/tab.go). После изменения файла перезапустите сервер.

| Подстановка | Значение |
| --- | --- |
| `{server}` | Строка Vitis |
| `{online}`, `{max}` | Текущее число игроков и настроенный лимит |
| `{tps}` | Сглаженная частота тиков сервера |
| `{cpu}` | Загрузка процессора; одно занятое логическое ядро — 100% |
| `{ram_mib}` | Резидентная память процесса в МиБ |
| `{generated_per_sec}`, `{sent_per_sec}` | Скорость генерации новых чанков и отправки их пакетов |
| `{chunk_avg_ms}`, `{chunk_last_ms}` | Время генерации: среднее за интервал и последнее |
| `{full_path_per_sec}` | Число новых чанков с первым подтверждением клиента за секунду |
| `{full_path_avg_ms}`, `{full_path_last_ms}` | Время от начала генерации до первого подтверждения клиента: среднее и последнее |

Данные обновляются раз в секунду. Метрики [прегенерации](pregeneration.md) отдельно учитывают запись чанков на диск.

Источники: [загрузка пакетов](../../internal/datapack/manager.go), [поиск датапаков мира](../../internal/datapack/discovery.go), [метрики списка игроков](../../cmd/vitis/live_tab.go).
