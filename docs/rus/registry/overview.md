# Реестры, теги и настройка клиента

[English](../../eng/registry/overview.md) · [Документация](../README.md)

## Назначение данных

- Встроенные реестры сопоставляют имена с числовыми ID выбранной версии.
- Реестры настройки клиента содержат записи с заранее закодированным NBT.
- Теги объединяют записи реестров по числовым ID.
- Датапаки загружают рецепты, добычу, достижения и генерацию мира в отдельный набор ресурсов.

Перезагрузка датапаков не пересоздаёт реестры протокола и не отправляет новые записи реестров уже подключённым клиентам.

## Создание реестров

[Manager](../../../internal/registry/manager.go) загружает встроенные соответствия и сгенерированные данные настройки клиента, затем проверяет результат. [IDRegistry](../../../internal/registry/registry.go) ищет записи по имени или ID. Если запись отсутствует, возвращает специальное значение, которое вызывающий код должен обработать.

[Встроенные адаптеры](../../../internal/registry/builtin.go) используют [сгенерированные данные](../../../internal/data/generated/registry/). Записи настройки клиента содержат имена и закодированный NBT. Идентификаторы и числовые типы NBT должны соответствовать версии Minecraft.

[Теги](../../../internal/registry/tags.go) формируют UpdateTags из сгенерированных данных. После смены версии проверяйте ID реестров и их участников.

## Обмен с клиентом

[Обработчик настройки](../../../internal/session/configuration_handler.go) предлагает встроенный пакет ресурсов, принимает ответ клиента, отправляет реестры и теги, затем завершение настройки. Подтверждение клиента завершает переход в игру.

Если клиенту известен предложенный пакет той же версии, NBT соответствующих записей можно не отправлять. Неизвестные и пользовательские данные передаются полностью.

## Генерация

[Генератор реестров](../../../internal/data/generator/registry/main.go) читает `registries.json` и каталоги датапаков выбранной версии. Он создаёт таблицы ID и NBT настройки клиента с явным выбором типов. Теги создаёт отдельный генератор.

Файлы и источники описаны в [подготовке данных](../generators/data-sources.md). Изменения состава реестров, типов NBT и адаптеров проверяются при [обновлении версии](../generators/version-upgrade.md).
