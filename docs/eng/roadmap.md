# Development directions

[Русский](../rus/roadmap.md) · [Documentation](README.md)

See [project status](status.md) for current features and limitations.

## Gameplay

- Complete Survival movement, combat, spawning, loot and experience rules for 1.21.4.
- Add the remaining item actions, enchantment effects and special menus.
- Complete block updates, redstone and container automation.
- Add vehicles, passenger handling, village behavior, raids and bosses.
- Complete Nether/End travel and respawn mechanics.
- Implement advancement triggers, statistics, signed chat and datapack functions.

World generation and structures are currently deferred.

## Extensibility and operation

- Develop a Go plugin and module API for third-party extensions.
- Extend permissions beyond operator levels.
- Evaluate proxy integration, metrics export and administration tools.
- Evaluate world storage improvements based on the existing Anvil support.
